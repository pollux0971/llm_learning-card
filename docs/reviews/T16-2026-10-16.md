## 4. 選的做法,以及為什麼

- **模式傳遞用 initialization script,不用 invoke、不用 URL。** 工單與 ADR-072 已經排除後兩種:invoke 會先畫一次錯的,URL 要改兩張卡。Rust 只組第一行 JSON,`window_mode.js` 用 `include_str!` 接在第一個換行之後,vitest 與 cargo 測同一個檔。頁面程式只碰 `document.documentElement.classList`;根元素是 null 就結束。
- **顯示閘門放 `ShowGate`,main.rs 只負責接線。** 載入完成與 3 秒逾時共用一顆 `Arc<Mutex<ShowGate>>`,先到的回 true 並 `show()`,後到的回 false。逾時那條用 `std::thread::sleep(SHOW_FALLBACK)`:Tauri 的 `show()` 是把訊息送回事件迴圈,不必自己 `run_on_main_thread`。逾時回 true 才 `log::warn!`,訊息帶視窗 label 與 `SHOW_FALLBACK`。
- **合成器建窗前問一次。** setup 跑在 GTK 已經 `gtk::init` 之後(Ready),所以不再呼叫 `gdk::init`(再叫會 panic)。`Screen::default()` 沒有時當作沒有合成器,走實心底,不要黑角。非 Linux 的函式回 true,這張不驗。
- **gdk 放在 `[dependencies]`,版本 `"0.18"`。** lock 只多了一行直接依賴,package 仍是唯一一份 0.18.2。沒有放進第二個 `[target.*.dependencies]`,因為量尺的正則會吃掉下一個區塊的開頭(待協調)。
- **window-state 用 `StateFlags::all() - StateFlags::VISIBLE`。** 位置與大小照舊還原,只拿掉「可見」,否則外掛會在頁面載入前把視窗打開。
- **縮小 / 關閉鈕不改 `HudTitleBar.svelte`。** 用跟 HudButton 一樣的偽元素: `::before` 是 1 像素黑線(`inset: -1px`,座標 +1px,左上與右下切角 5px),`::after` 是跟著 `--hud-panel` 的內底。按鈕自己 `z-index: 0` 開堆疊上下文,`::after` 用 `z-index: -1` 才不會蓋住字,也不會被切角裁掉伸到外面的線。hover / focus 只換偽元素:框線 `--hud-accent`,內底 `color-mix(in srgb, var(--hud-accent) 35%, transparent)`(跟 HudButton 同一組,比 accent-wash 的 16% 深)。focus-visible 再加 T14 的淺色內框(`--hud-solid` 的 2px 線)。任何狀態 `outline: none`,拿掉原來的方形 outline。
- **停用鈕的橘色用 `:not(:disabled)`。** 既有 `[data-hud="button"]:hover::before` 對停用鈕也生效。框線與淡橘內底都加上 `:not(:disabled)`;作答欄的橘框加上 `:not(:has(:disabled))`。停用仍靠既有的 `opacity: 0.45` 跟一般狀態分開。
- **縮放把手 hover 不再填 `--hud-accent`。** 改成 `background-color: transparent`、`background-image: none`。游標本來就寫在各邊的規則上,hover 只留游標。
- **展示頁。** 加 `data-gallery="fake-window-controls"` 的 checkbox;勾了把 `available: true`、四個方法都是空 Promise 的 controls 交給 HudPanel。停用的 `HudButton` 與 `input disabled` 放在現有三顆按鈕、兩個作答欄後面,索引不動。
