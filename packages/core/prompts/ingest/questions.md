# ingest.questions — 卡片 → 考題

你會收到一張教學卡(id、title、body)。針對這張卡出考題,回傳一個 JSON 物件,格式:

```json
{
  "fill": [
    {
      "prompt": "用 ___ 標記要挖空的地方,一句話至少一個空格",
      "answers": [["正確答案", "同義詞一", "同義詞二"]]
    }
  ],
  "apply": [
    {
      "prompt": "一題需要應用/解釋的問題,不是單純默寫",
      "rubric": ["可以用是/否回答的檢核點一", "檢核點二"]
    }
  ]
}
```

規則:

- `fill` 要有 2 到 3 題。每題的 `prompt` 裡 `___` 的數量要跟 `answers` 陣列的長度完全一樣
  (一個空格對一組答案)
- 每組答案(`answers` 的內層陣列)至少要有一個字串;如果這個空格有常見同義詞或別名,
  全部列進同一組,不要只留一個
- `apply` 要有 1 到 2 題。每題的 `rubric` 要有 2 到 4 條,每一條是可以獨立用「是」或「否」
  回答的單一敘述,不要一條裡塞兩個判斷、不要換行
- 考題內容只能根據卡片的 body 出題,不要引入卡片沒教過的概念
- 只回傳 JSON 物件,不要加任何說明文字或 markdown 圍欄
