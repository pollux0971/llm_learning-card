## 觀察

- **O1(請顧問看要不要管)沒有合成器時,視窗 map 之後偶爾有一張還是舊的螢幕內容。**
  - 只卡教學卡那一次:考試卡 map 之後 17 ms 那一張,它的切角與取樣點全是**桌面底色** (46, 139, 87),下一張(約 117 ms)切角就是 (244, 246, 248)。0 個黑點,照工單的定義不是黑幀。
  - 20 ms 第 3 次:考試卡 map 那一毫秒讀的那一張切角沒對上,也不是黑的(顏色沒留下);同一毫秒讀的那一張也可能是 map 之前開始讀的。補拍的 3 次沒有再出現。
  - 看起來的原因:沒有合成器時,X server 在視窗第一次畫之前留著原本螢幕上的東西(這裡是桌面底色),不是黑色。只卡教學卡那次,考試卡跟教學卡的 3 秒退路同時顯示,主執行緒剛好忙,第一次畫晚了一點。
  - 使用者看到的是「那一格閃過一張桌面」(不到 117 ms 的空窗),不是 T16 那種黑塊。工單驗收 7 只擋黑,這個不擋。要不要另外處理(例如讓 X 視窗的 background pixel 也設成 `--hud-solid`),請顧問判。
- **O2 第一批 `:1` 的 10 次作廢**:取樣程式在作答欄那一步出錯(這版 WebKit 的檢查器不等 async 的結果),出錯後沒有關 app,下一次開的又抓到上一個 app 的視窗,資料全部不能用,已刪。
  留在使用者桌面上的 3 個 app(暫存根的,不碰真的 learning/)用 `WM_DELETE_WINDOW` 關掉、確認行程都結束;沒有送任何鍵盤滑鼠。之後把程式改成「出錯也一定關 app、開跑前桌面上不准有本 app 的視窗」,再開正式的 10 次。
- **O3** 冒煙第一次也是取樣程式的錯(把純文字的回應當 JSON 讀),app 由收尾程式關掉;修好重做的那一次就是上面的結果。
