- 連跑 3 次,每次 10/10。
- 把 c4 門檻暫時收到 0.01 看實際差:按鈕 y 差 0.375 px(中間 355.45、最底 355.08),餘裕 0.125 px。換三種內容長度(長例子的字數 30、31、34、37 行)數字都一樣,是確定性的(版面是 1/64 px 的格子),不是隨機抖動。
