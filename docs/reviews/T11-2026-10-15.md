## 4. 做了什麼

1. `gitCommitOf(relPath, root?)` 改成匯出。`root` 預設 `ROOT`。先 `git log -1 --format=%h -- <檔>`;沒有 sha(沒追蹤、沒有 commit、不是 git repo)回 `uncommitted`,不加後綴。有 sha 時,`git diff --quiet -- <檔>` 與 `git diff --cached --quiet -- <檔>` 任一退出碼不為 0,回 `<短 sha>-dirty`。只把這個檔傳給 git,不看整個 repo。
2. 拒絕看解析後的輸出路徑,不分 mode。prompt 是 dirty,而且輸出目錄的 realpath 落在 `<root>/packages/core/src/prompt-quality/golden/` 底下(含它本身)就丟 `DirtyPromptError`(`name`、`set`、`promptFile`;訊息含 prompt 檔相對路徑、`dirty`、未提交、`--out`,並講先提交或把 `--out` 指到 golden/ 以外)。`baseDir` 還不存在時,取最近存在的祖先做 realpath 再接回剩餘路徑;golden/ 自己的位置也 realpath。比的是路徑邊界(`path.relative`),不是字串前綴,所以 golden-fake/、golden-extra/ 不算。這一步在建立 router、`probeOnline`、`router.call`、`mkdir` 之前。
3. `RunGoldenOptions.root?`、`defaultGoldenBaseDir(mode, root?)`、`main(argv, deps?: { root? })`。不給 `root` 時 `defaultGoldenBaseDir` 仍回既有常數,prompt 檔與 git 仍問 `ROOT`。給了 `root` 才把預設存放處、讀檔、問 git 搬到那個 repo。CLI 把 `deps.root` 原樣傳給 `runGolden`,接住 `DirtyPromptError` 後退出碼 1。
4. types.ts 的 `promptFileGitCommit` 註解補上 `-dirty` 後綴:`uncommitted` 不加後綴;`-dirty` 不等於任何乾淨的 sha。
5. 沒有改 `detectPromptDrift`、既有 golden/ 基準、`packages/core/prompts/`。fake 的 fixture 目錄仍是真 repo 的那份(測試的 mkdtemp repo 沒有 fixture)。
