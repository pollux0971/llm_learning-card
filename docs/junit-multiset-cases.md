# junit 測試名單比對:實際案例

每次合併之後比對 testcase 的**名單**(不是總數),做法與理由寫在
`.claude/skills/autopilot/SKILL.md` §2。**這份檔案只放案例** —— 理由會被人重寫,
案例不會,而且下一個人要的是「這招真的抓到過什麼」。

⚠️ **這份檔案裡的數字都是當時量到的,不是永久事實。** 要用就當場重量。

---

## 案例 1 · 總數相等,內容少了四條(別的專案)

```
branch  8044 = 8036 + 4 + 4
main    8044 = 8036 + 8
```

**兩邊總數一模一樣。** 只看數字的人會說「沒問題」——**而實際上分支少了四條、
另外多了四條不同的。**

**這是「不要比總數」的原始理由。**

---

## 案例 2 · 「9 組同名」是量法的產物,不是事實

用 `name` 比,量到 **9 組同名**;用**完整限定名**(`classname` + `name`)比,
**3143 筆全部唯一,0 組同名**。

**那 9 組不是資料的性質,是量法的性質。** 換一個量尺它們就消失了。

**所以比對一律用完整限定名。** 輸出同時列出兩種數字,下一個人一跑就看得到差別 ——
**不要把「9」寫死進任何地方當事實。**

(2026-09-13 第三次驗證:仍然是 `name` 9 組 / 完整限定名 0 組。)

---

## 案例 3 · 為什麼是 multiset 而不是 set(這一條是推導,不是實測)

**一條測試被改名**,`set` 比對會同時看到「少一個舊名、多一個新名」→ **算平手**。
**multiset 才看得出組成變了。**

⚠️ **這一條在 2026-09-13 之前都只是推演。** 案例 4 是它第一次真的發生。

---

## 案例 4 · 第一個真實案例:它給的是「歸因」,不是「偵測」

**2026-09-13,`9a36483` vs `73ec1bd`:**

```
舊 3224 → 新 3232
消失:2
  - packages/core/src/llm/spend.test.ts :: isLlmCallEvent > 只認 llm_call 而且 provider 是 openai 的事件
  - packages/core/src/llm/spend.test.ts :: isLlmCallEvent > anthropic 也不算:ADR-034 決定雲端只用 OpenAI,預算就是 OpenAI 的預算
新增:10
  + x6  scripts/check-ledger-pollution.test.ts
  + x4  packages/core/src/llm/spend.test.ts
        · isLlmCallEvent > 只認 llm_call 且排除明確免費的 ollama
        · isLlmCallEvent > anthropic 要算:provider 選擇與花費計算是兩件事
        · isLlmCallEvent > 沒見過的 provider 也要算:排除法預設煞車
        · computeDailySpend > anthropic 的雲端事件也計入花費
只用 name 的同名組數  舊 9 新 9
完整限定名的同名組數  舊 0 新 0
```

**三種量法會給你三種答案:**

| 量法 | 看到什麼 | 夠不夠 |
|---|---|---|
| 只比總數 | 淨增 8 | **看起來一切正常** |
| 用 set 比 | 同一個檔裡改名 → 算平手 | **看不到** |
| **multiset + 完整限定名** | **2 消失、10 新增,逐條列名** | ✓ |

⚠️ **而它真正給的東西,比「偵測到有東西消失」更前面一步:**

> **它告訴我的不是「有東西消失」,是「消失的正好是我要它刪的那兩條」。
> 那是「歸因」而不是「偵測」,而歸因才是 multiset 存在的理由。**

**逐條列名逼我去回答「這兩條是我要它刪的嗎」** —— 是,而且第二條正是工單裡點名
要反轉的那一條(花費計算從「白名單 openai」改成「排除 ollama」,所以
「anthropic 也不算」那句必須反過來)。

### 附帶標一件那個 worker 做對的事

**它連測試名裡的舊理由都改掉了**(`ADR-034 決定雲端只用 OpenAI` → `provider 選擇與
花費計算是兩件事`),**沒有只改斷言、留著舊理由**。

**留舊理由是最常見的偷懶**,而它會讓下一個人讀到一個已經被推翻的理由 ——
同「**理由過期比狀態過期更難察覺,因為沒有人會去重驗一個理由**」。
