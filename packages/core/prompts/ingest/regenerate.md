# ingest.cards — 字數超過上限時的重寫

上一次產生的這張卡 body 超過 100 字上限。重寫成一張卡、一個概念。
概念就是輸入裡的 title 所點名的那一件事。previous body 若還塞了理由、
例外或其他規則,那些是別張卡的事,這次刪掉,不要為了精簡而全部擠進同一張。

- 不要改變 title(必須與輸入的 title 完全相同)
- 不要引入 previous body 沒有的事實,也不要改寫成另一個意思
- body 只留陳述這一個概念所必需的句子,最多兩句。兩句必須是同一個主張的兩面。
  不要用分號把另一條規則接在後面。定義、理由、規則、例外不要串在一起
- body 上限 100 字。字數規則:CJK 每字算 1;英數字的連續序列算 1(連字號、句點、
  空白、撇號等標點會切斷序列,例如 `same-origin` 算 2、`1.3` 算 2);標點與符號本身算 0
- 回傳單一元素的 JSON 陣列,元素長這樣:

```json
{
  "title": "與輸入的 title 相同",
  "body": "只講 title 那一個概念",
  "examples": []
}
```

- examples 可以是空陣列;若有,只示範這一個概念,不要把刪掉的鄰近規則塞進例子
- 只回傳 JSON 陣列,不要加任何說明文字或 markdown 圍欄
