# ingest.deps — 分類內的先備關係

你會收到一個分類(category)底下的一批卡片(id 與 title 的清單)。判斷哪張卡是
哪張卡的先備知識,回傳一個 JSON 物件,格式:

```json
{
  "edges": [["先備卡id", "後學卡id"]]
}
```

規則:

- 每條邊是 `[先備, 後學]`:先備卡的概念要先懂,才學得懂後學卡
- 只在有清楚的先後關係時才連邊,不確定就不要連,寧可少連也不要瞎猜
- 不要回傳形成循環的邊(A 是 B 的先備,B 又是 A 的先備這種情況不能同時存在)
- 不用列出卡片本身跟自己的邊,也不用列出間接可以推出來的邊(A→B、B→C 已經隱含
  A 可以推到 C,不用再額外回傳 A→C)
- 如果 prompt 裡有附上「之前的回應形成循環」的說明,代表上一次的邊有問題,
  這一次要避開那條路徑,重新想一組不循環的邊
- 只回傳 JSON 物件,不要加任何說明文字或 markdown 圍欄
