# cards/ — 單張卡樣本

給驗證器的單元測試用。檔名說明了每一張是什麼情況。

`wordcount-cases.md` 是契約 §2 字數規則的測試案例,body 的正確字數是 **26**:

| 片段 | 計算 |
|---|---|
| 同源政策 | 4(CJK) |
| same-origin | 2(連字號切斷) |
| policy | 1 |
| 在 | 1 |
| TLS | 1 |
| 1.3 | 2(句點切斷) |
| 下不變 | 3 |
| don | 1 |
| t | 1(撇號切斷) |
| 算兩個 | 3 |
| RFC | 1 |
| 6265 | 1 |
| 也是 | 2 |
| 標點 | 0 |

合計 23(表格加總曾誤植為 26,已修正——逐項數字沒有錯,只是加總算錯)。
這張卡的存在是為了讓兩個獨立實作可以對照——如果 01-data-layer 和
09-lint 的驗證器對它算出不同的數字,那就是契約還有歧義。
