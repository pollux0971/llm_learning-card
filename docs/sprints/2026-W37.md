## ⚠️ 花錢的煞車在 `--live` 這條路上沒有接(2026-09-12)

安排 `12-prompt-quality/phase-2` 的第一次真實基準時,依序撞到三個洞:

1. **`.env` 少兩個鍵。** `.env.example` 列 10 個,實際 7 個,**少的正好是
   `LLM_CLOUD_PROVIDER` / `LLM_CLOUD_MODEL`** —— live 路徑完全靠它們。
   ⚠️ 而錯誤訊息說「**現在連不上**」,把**設定問題講成網路問題**
   (實測網路是通的:`api.openai.com` HTTP 401、`example.com` HTTP 200)。
2. ⚠️ **真的呼叫完全沒有進 `learning/state/log.jsonl`。**
   `router.ts:29` 的 `createFileLogAppender(undefined)` 是**靜默 no-op**;
   而 `golden-run.ts:262` 的 `createDefaultLiveRouter()` **既沒給 `logPath` 也沒給 `settings`**。
   另外兩個正式入口(`scripts/llm.ts`、`scripts/ingest.ts`)**都有給** —— 只有這一個漏。
   **後果:`--live` 可以無限跑,每日上限一次都不會觸發,而且它回報的是「確信的零」,
   不是「算不出來」。「這條路不回報」跟「今天沒花錢」在輸出上一模一樣。**
3. **`gpt-5.6-luna` 不在價目表上**,所以就算修好第 2 條,錢還是算不出來。

實際花掉:**3 次呼叫、token 進 1702 出 2662,手算約 US$0.031。**
發現後**立刻停止**,5 組只跑了 1 組,產出留在
`packages/core/src/prompt-quality/golden/ingest.cards/2026-09-12/` **未 commit**
(一份看起來完整的部分基準比沒有基準更糟)。

## Retro

- **哪個 phase 比預期難?** 沒有 phase。難的是「發現量尺在說謊」這件事本身。
- **為什麼?** 因為壞掉的量尺**不會報錯**,只會回報一個看起來正常的數字。
  本週抓到的六個全部是這個形狀。
- **下週要改估法或拆法嗎?** 要改的是**分配**:連續一週沒有 feature phase 推進,
  而唯一 gate 解除的那個等了 8 天。維護清單第 3 項的規則
  (「連續 3 輪沒被碰過就升級成工單」)**應該也套用在「gate 已解除但沒人排」的 phase 上**。
- **契約缺東西嗎?** 沒有。缺的是「**呼叫 LLM 必須可記帳**」這條被程式強制,而不是靠呼叫方記得。
- **這週有沒有改過 prompt?** 沒有。跑了一次 live golden(`ingest.cards`),沒有改任何 `prompts/`。
