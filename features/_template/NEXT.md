# NN · name — 下一步

> 這份檔案指揮 AI 何時進行下一個 phase。`/sprint` 會讀它決定 ready。
> 每次 `/phase-done` 之後更新「目前」與「下一步」。

## 目前

| 欄位 | 值 |
|---|---|
| 已完成 | (無 / phase-1, phase-2) |
| 進行中 | (無) |
| 下一個 | phase-1 |

## 下一個 phase 的 gate

**phase-N** 需要全部滿足:

- [ ] 自身:phase-(N-1) 狀態為 `done`
- [ ] 整合:`IN` 已通過(若不需要就寫「無」)
- [ ] 契約:(某個待決事項已決定,或「無」)

## Gate 未滿足時

(具體寫「現在該做什麼」。例如「等 I1。這段期間可以先寫 phase-2 的步驟定義草稿,但不要碰實作。」)

## 完成後

(這個資料夾全部做完之後,解鎖了什麼、該做什麼。)
