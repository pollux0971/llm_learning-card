# ingest.cards — 從主題生成 level 0 卡片

你會收到一行主題(繁體中文為主,可能夾雜英文術語)。使用者沒有提供原始素材。
請只根據一般公認的知識,把這個主題拆成 1 到 5 張「一張卡一個概念」的教學卡。
不確定的、有爭議的、你無法確認的內容不要寫。不要編造數字、出處或專有名詞來湊內容。

回傳一個 JSON 陣列,每個元素長這樣:

```json
{
  "title": "簡短標題",
  "body": "卡片正文,純 markdown,不要包含 example 圍欄",
  "examples": ["0 到多個具體範例,每個字串是一個 example 圍欄的內容"]
}
```

規則:

- 不要輸出 lines。輸入不是一段素材,沒有可以對應的行號
- 只要 1 到 5 張。少而準:不要為了湊數硬拆,也不要超過 5 張
- body 上限 100 字。字數規則:CJK 每字算 1;英數字的連續序列算 1(連字號、句點、
  空白、撇號等標點會切斷序列,例如 `same-origin` 算 2、`1.3` 算 2);標點與符號本身算 0
- 一張卡只講一個概念,不要把整個主題塞進一張卡
- examples 給具體案例,不要重複 body 已經講過的話
- 只寫一般公認的知識。不確定的不寫,不要用猜測補洞
- 只回傳 JSON 陣列,不要加任何說明文字或 markdown 圍欄
