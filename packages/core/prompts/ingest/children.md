# ingest.cards — 父卡 → level 1 子卡

你會收到一張已經存在的教學卡(parent_id、parent_title、body),當作「父卡」。
只從這張父卡的 body 裡,挑父卡點到但沒講完的面向,拆成更深入的子卡。
回傳一個 JSON 陣列,每個元素長這樣:

```json
{
  "title": "簡短標題",
  "body": "卡片正文,純 markdown,不要包含 example 圍欄",
  "examples": ["0 到多個具體範例,每個字串是一個 example 圍欄的內容"]
}
```

規則:

- 回傳 1 到 3 個元素,一個元素一張子卡。寧願少,不要為了湊滿 3 張而補一張不合格的
- 一張子卡只講一個新斷言:父卡 body 沒有直接說完的那條界線(什麼情況仍算、什麼情況不算、做了會怎樣)
- 不要出這三種:
  - 重述:父卡已經斷言的句子,換個說法、或只補一個標頭名 / 數字,主張仍相同。例:父卡已寫「結果可以快取一段時間,少一趟往返」,不要再出一張「快取時間」
  - 前置知識:父卡假定讀者已知、body 沒有在教的概念。例:父卡在講伺服器如何授權跨來源讀取,不要另出「來源由協定、主機、埠組成」
  - 鄰近主題:父卡 body 完全沒提到的機制,不要從別的主題搬進來
- 可以點出父卡已在講的規則所對應的標準名稱,但只有在它劃出父卡沒說的界線時才出一張卡。只為了把父卡的句子配上名字,不要出
- 新斷言必須能從父卡 body 推得出來,不要編父卡沒有支撐的事實。找不到這樣的面向就少回一張,不要硬湊
- title 不要與 parent_title 相同,也不要用父卡 body 的結論句當標題。不要逐字抄父卡的句子
- body 上限 100 字。字數規則:CJK 每字算 1;英數字的連續序列算 1(連字號、句點、
  空白、撇號等標點會切斷序列,例如 `same-origin` 算 2、`1.3` 算 2);標點與符號本身算 0
- 子卡沒有自己的原始素材(不是切自 raw),不用附行號
- examples 只示範這張子卡的新界線,不要把父卡或 body 已經講過的話再寫一次
- 只回傳 JSON 陣列,不要加任何說明文字或 markdown 圍欄
